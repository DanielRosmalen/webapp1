# Snackbar Ordering System

This is a PHP web application I built during my first year. It is a functional ordering website for a snackbar. I made this to learn how to connect a front-end with a back-end and how to handle data.

## Features
* **Working Shopping Cart:** Users can add snacks to their cart and place an order.
* **Admin Panel:** A backend dashboard where the owner can manage things.
* **Responsive:** It looks good on both desktop and mobile phones.

## Built with
* PHP
* MySQL (Database)
* HTML & Custom CSS
* javascript (not selfmade)

## How to run locally
Because this project uses PHP and a database, you need a local server like XAMPP or MAMP to run it.
1. Download the files and place them in your `htdocs` folder.
2. Open phpMyAdmin and create a new database.
3. Import the `restaraunt.sql` file (included in this repository).
4. (Optional) Check the database connection file in the code to ensure the credentials match your local setup.
5. Open `localhost/map-name` in your browser.
